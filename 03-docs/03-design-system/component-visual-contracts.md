# Component Visual Contracts

**Document type:** Design-system specification — shared component visual contracts
**Recorded by:** Task LRG-DS-005 (Phase 3)
**Date:** July 25, 2026
**Status:** **PROPOSED — founder review required**
**Authority:** Global Shell v1.1 §0.2 (binding reuse outcomes), §5–§6 (navigation), §7 (Search and Ask), §18–§21 (visual direction), §35 (GS-09 bottom navigation), §39 (GS-13 ad rail/anchors), §122 (ad system), §123–§126 (trust and safety sections), §143–§147 (accessibility) · `design-system-specification.md` · `token-reuse-register.md`

**Scope.** These are **visual and accessibility contracts only**. No component is implemented, no page-family section ordering is defined, and no page-specific ad volume is set. Section order remains governed solely by the page-family blueprints; Global Shell §154 reserves page-specific hierarchy for those blueprints.

**Universal contract — applies to every component below.** Colour is never the sole signal. Every interactive element has a visible `:focus-visible` indicator at ≥3:1 that is never obscured by sticky layers. Targets are 44 × 44 px where practical. All states from §4.8 of the specification are implemented where applicable. Nothing is rendered as an available action when it is not. No component may be styled to resemble an advertisement, and no advertisement may be styled to resemble a component.

## 1. Structure and Shell

| Component | Purpose | Visual hierarchy | Token usage | Responsive behaviour | States | Accessibility contract | Prohibited treatments |
|---|---|---|---|---|---|---|---|
| **Global container** | Constrain and centre content | Neutral; invisible | `--layout-content-max` (≈1280 px), gutters 16→24→32 px, `--layout-measure` 65–75ch for prose | Full-bleed bands wrap content in the container; tables and result grids may use full content width | — | No horizontal page scroll at any validation width | Prose at full width; nested containers |
| **Site header** | Stable identity, navigation, search, AI entry, account | Highest authority; above all page content | `--color-brand-navy` or `--color-surface`, `--color-border` (≥3:1) bottom boundary, `--elevation-1` when sticky | Desktop: inline primary nav + utility. Below the named threshold: compact top app bar; nav moves into the mobile menu | Default, scrolled/sticky, anonymous, signed-in | Landmark `banner`; skip-to-content first in tab order; mega menus open by **button** with `aria-expanded`/`aria-controls`, Escape closes, focus returns to trigger; no hover-only content | Hover-only menus; icon-only controls without accessible names; hiding navigation the blueprints require |
| **Mobile navigation** | Primary navigation on small screens | Persistent bottom bar; peer to content, subordinate to safety | `--color-surface`, `--color-border`, `--color-nav-active`, safe-area insets | Bottom bar below the named threshold; hidden above it | Default, active (`aria-current`), badge present | **Text labels required** *(Global Shell §144)*; bypassable by assistive technology; badges have meaningful accessible names; **priority 2** in the sticky order — outranks advertising | Icon-only tabs; consuming excessive viewport height; overlapping the sticky ad; hiding beneath an ad |
| **State context selector** | Choose the jurisdiction that governs results, eligibility, claims, tax | Prominent but subordinate to the page task | `--color-surface`, `--color-border` (≥3:1), `--color-action-primary` for confirm | Inline on desktop; inside the mobile menu or a sheet on mobile | Default, open, selected, uncertain, unavailable | Native select or a fully keyboard-operable listbox with a real `<label>`; **when state context is uncertain the UI asks rather than silently choosing** *(Global Shell §6.5)*; announces the resolved state | A hardcoded single-state control (the current Florida-only disabled select); implying IP location determines eligibility |
| **Search** | Find states, games, results, content | Visible at desktop and mobile; paired with the AI entry | `--color-surface`, `--color-border` (≥3:1), `--color-focus` | Full-width field or icon-expand on mobile | Default, focused, typing, suggestions open, empty result, error | `role="combobox"` semantics with `aria-expanded`/`aria-activedescendant`; results announced politely; Escape closes and returns focus; keyboard-only operable | A visual-only search that is not a real form control; suggestion lists unreachable by keyboard |
| **Ask / AI entry** | Contextual invitation to AI relevant to the surface | Present after the immediate answer, never before it | `--color-ai` (darkened for any text), bounded region, `--radius-md` | Inline contextual entries at all widths; compact label variant on mobile | Default, submitting, streaming, complete, stopped, restricted, error | **Explicit AI label** *(Constitution §13)*; **"answer complete" status**; **stop-generation control**; streaming must not continuously overwhelm screen readers; sources and actions keyboard reachable; generated content uses semantic headings, lists and tables *(Global Shell §145)* | A generic floating chat bubble as the whole AI strategy *(Constitution §13)*; sci-fi or gradient chrome; any implication of predictive power; an AI identity that appears human |
| **Jackpot ticker** | Next draw and top jackpots at a glance | Supporting band; must not outrank the page's primary answer | `--color-surface-band` (must fix the 3.91:1 muted-text failure), `--color-jackpot` as fill with dark text | Full-bleed band; horizontally scrollable within its own container on mobile with a visible affordance | Default, loading, stale, unavailable | Amounts as text with tabular numerals; **"estimated jackpot"** wording; exact next-draw date when "tonight" is ambiguous; scroll container is keyboard reachable | `--color-jackpot` as text on light (1.85:1); countdown urgency styling; motion |
| **Breadcrumb** | Position and upward navigation | Low visual weight, above the page heading | `--color-text-muted` (≥4.5:1 on its background) | Wraps on mobile; never truncated to meaninglessness | Default, current | `nav` with an accessible name; current item marked `aria-current="page"`; **must mirror the `BreadcrumbList` schema** — schema reflects visible content only | Colour-only current indication; hiding breadcrumbs on mobile |
| **Page heading** | The page's single primary heading | Strongest text on the page | H1 scale, `--color-text` | 24–28 px mobile → 32–36 px desktop | Default | Exactly one `h1` per page; unique; no skipped heading levels beneath it | Decorative text replacing a real heading; multiple `h1` |

## 2. Results and Data

| Component | Purpose | Visual hierarchy | Token usage | Responsive behaviour | States | Accessibility contract | Prohibited treatments |
|---|---|---|---|---|---|---|---|
| **Result card** | Deliver one game's drawn result — the highest-priority content on results surfaces | **Highest** on state, game and result surfaces; renders before AI, ads, promos and engagement | `--color-surface`, `--color-border` (≥3:1 — surface-vs-canvas is only 1.07:1), `--radius-md`, `--elevation-0` | One-up mobile → two/three-up desktop; ball rows wrap; **compact density** *(Global Shell §21)* | Latest, awaiting, closed, stale, corrected, unavailable, loading | Article/section with the game as its heading; **draw date and game announced before values** *(Global Shell §146)*; status is text, not colour; prize and next-draw as text | **No ad inside the card**; no ad between the jackpot and the numbers; nesting more than one card level on mobile; celebratory motion |
| **Number ball** | Render one drawn value | Strongest numeric emphasis inside its card | `--ball-*` pairs; `--radius-full`; standard pair 17.85:1 | Fixed size with `space-2` gaps; wraps cleanly through 20+1 sets; scales one step up on desktop | Standard, special (per type), add-on, awaiting placeholder, corrected | **Numbers are real crawlable text, never image-only.** Every special type carries a **visible label + border/shape treatment + accessible name** — colour is incapable of the distinction (1.09–1.30:1 between specials). Tabular numerals. **Game-defined order never re-sorted.** Fireball needs a compliant pair (3.56:1 today fails) | Colour as the only distinction; image-rendered numbers; hardcoded ball counts; reordering for visual balance |
| **Data table** | Present structured rows — history, jackpots, comparisons, winners | Content-level; full content width permitted | `--color-surface`, `--color-border` (≥3:1 cell boundaries), `--color-surface-subtle` for striping | **Scrolls within its own container with a visible affordance** *(Global Shell §20)* — never the page | Default, sorted, empty, loading, stale, paginated | `<caption>` and `<th scope>`; sort state via `aria-sort` **plus** a non-colour indicator; scroll container keyboard focusable and labelled; tabular numerals in numeric columns | Page-level horizontal scroll; colour-only sort indication; div-based pseudo-tables; ads inside the table body |
| **Quick-facts table** | Compact label/value facts | Supporting, near the top of a hub | `--color-surface`, `--color-border-subtle` where a compliant boundary already exists | Two-column desktop → stacked pairs on mobile | Default, empty, stale | Real table or description list with programmatic label/value association | Free-floating text pairs with no association |
| **Schedule table** | Draw days and times | Supporting | as data table; tabular numerals for times | Stacks or scrolls in-container on mobile | Default, empty, changed | Times include the applicable timezone label; **game-local draw meaning preserved**; changed schedules flagged in text | Ambiguous "tonight" without a date; timezone omitted |

## 3. Content, Guidance and Trust

| Component | Purpose | Visual hierarchy | Token usage | Responsive behaviour | States | Accessibility contract | Prohibited treatments |
|---|---|---|---|---|---|---|---|
| **Information callout** | Non-critical clarification | Subordinate to the answer it supports | `--color-info-surface`, `--color-info-border` (≥3:1 — 1.31:1 today fails), icon, `--radius-md` | Full content width; stacks | Default, dismissed (if dismissible) | Icon **plus** text label — never colour alone; not a live region unless the content is dynamic | Reusing this treatment for advertising bands; using it for corrections or errors |
| **Warning / correction notice** | Announce an error, correction or high-consequence condition | **Elevated above ordinary content**, adjacent to the affected value | `--color-alert` / `--color-corrected`, compliant boundary, icon | Full width; never collapsed by default | Correction, error, high-consequence | **"Corrected" label + what changed + when + impact** *(Global Shell §126)*; announced with the value; assertive only for genuine errors | Silent correction; burying below the fold; transient flash; ads adjacent inside the protected zone |
| **FAQ** | Answer common questions in visible text | Content-level, lower in the page | `--color-surface`, `--color-border`, `--radius-md` | Full width; stacks | Collapsed, expanded | Native disclosure semantics; keyboard operable; heading structure preserved. **`FAQPage` schema only when the FAQ is visible** *(`CLAUDE.md` §11)* | Schema for hidden FAQs; content only reachable by hover |
| **Tabs** | Switch between peer views or jump to sections | Navigation-level, below the page heading | `--color-nav-active` fill or indicator + weight change | Horizontally scrollable on mobile with a visible affordance; never truncated to ambiguity | Default, selected, focused, disabled | If tabs (`role="tablist"`): arrow-key navigation, `aria-selected`, panel association. If in-page anchors: `nav` + `aria-current`. **Selected state uses fill/indicator plus weight — never colour alone** | Colour-only selection; anchor links styled as tabs without either contract |
| **Source / methodology block** | State where data came from and how it is maintained | Compact, persistent, low chrome | `--color-text-muted` (≥4.5:1), `--color-border-subtle` | Inline compact row → stacked on mobile | Default, verified, stale, correction present | "Source checked · Result verified · Last updated" *(Global Shell §123)*; timestamp as real text; **"official" only where the distinction materially matters** *(Constitution §24.1)* | Implying LotteryCorner is an official lottery; repetitive page noise; hiding provenance |
| **Responsible-play block** | Deliver responsible-play guidance and the 18+ notice | Calm, clearly bounded, never alarming | `--color-surface`, `--color-border-subtle`, low chrome | Full width | Default | Real headings and links; reachable by keyboard; **promotion and commerce suppressed inside it** | Any ad or commercial CTA inside; stigmatising imagery; burying it |

## 4. Actions, Forms and Commerce

| Component | Purpose | Visual hierarchy | Token usage | Responsive behaviour | States | Accessibility contract | Prohibited treatments |
|---|---|---|---|---|---|---|---|
| **Buttons and links** | Invoke actions and navigate | Primary > secondary > tertiary > plain link | `--color-action-primary` (subject to the §4.2.7 role decision), `--color-action-secondary`, `--color-text-inverse`, `--radius-md`, `--color-focus` | Full-width primary action on mobile where it is the page task; inline on desktop | Default, hover, focus-visible, active, disabled, loading | Buttons for actions, links for navigation — never inverted; ≥44 × 44 px; label ≥14 px; **disabled must not read as available** and carries a reason; loading announces politely and reserves its space | Colour-only affordance; icon-only buttons without accessible names; `<div>` acting as a button |
| **Forms** | Collect input for tools, search, subscription | Field-level; label always visible | `--color-surface`, `--color-border` (≥3:1), `--color-focus`, `--color-alert` for errors | Single column; 16 px inputs to prevent iOS zoom; the virtual keyboard must not hide the input or its action *(Global Shell §147)* | Default, focused, filled, invalid, disabled, submitting, success | Persistent visible `<label>` — **never placeholder-as-label**; errors identified in text, associated programmatically, focus moved to the message; success announced politely; accessible authentication where applicable *(Global Shell §143)* | Placeholder-only labelling; colour-only error indication; a visibly enabled control that does nothing |
| **Campaign module** | Internal promotion in an approved content placement | Clearly subordinate to page content; distinct from advertising | `--color-info-surface` or `--color-brand-navy` variant, compliant boundary | Full content width; stacks | Present, absent (renders nothing) | Landmark or region with an accessible name; internal destinations only; targeting data never exposed in the DOM | **Never replaces, moves, collapses or reorders a GAM slot**; never styled as a result or jackpot card; never styled as an advertisement |
| **Affiliate CTA** | Route to an approved purchase destination | Prominent **after** the value is delivered — never before | `--color-action-primary`, `--color-commerce-disclosure` for the adjacent disclosure | Full-width on mobile where appropriate; inline on desktop | Eligible, ineligible for state, unavailable, stale eligibility (suppressed) | **First-party resolver route only — no raw affiliate URL in DOM, metadata, schema or fixtures**; `rel="nofollow sponsored"`; **explicit disclosure adjacent**; state eligibility stated in text | Presenting an affiliate as an official lottery; urgency or loss framing; commerce inside a protected zone; hardcoded external destination |
| **Signed-in continuity module** | Surface saved games, followed states, saved numbers and alerts | Additive to the anonymous experience — never replacing public value | `--color-surface`, `--color-border`, `--color-success` for saved confirmations | Stacks on mobile; may occupy the contextual rail on desktop | Anonymous (not rendered or shown as an invitation), signed-in, empty, loading, error | Region with an accessible name; saved-state changes announced politely; **public value remains complete without an account** *(Constitution §17)* | Gating public facts behind sign-in; **any paid-tier, quota, export, ticket-record or Insider-badge treatment — all blocked pending the 11 open Member/Insider founder decisions**; a disabled login control presented as functional |

## 5. Advertising

Presentation only. No slot count, ID, GAM unit, mapping or placement is defined or altered here.

| Component | Purpose | Visual hierarchy | Token usage | Responsive behaviour | States | Accessibility contract | Prohibited treatments |
|---|---|---|---|---|---|---|---|
| **Ad container** | Host one fixed GAM placement without disturbing content | **Lowest** — always after the value it follows | `--color-ad-placeholder` (visually distinct from `--color-info-surface`), `--radius-md`, compliant boundary, `--type-label-micro` (12 px floor) label in `--color-text-muted` | Space reserved from the slot's own mapping **before** any request; reserved height changes only at the single named threshold; mobile-only slots visible below it and hidden above — **visibility and layout share one threshold** | Reserved, loading, filled, **no-fill** | Visible **"Advertisement"** label; `role="complementary"` with an accessible name; excluded from the content reading flow; never a keyboard trap | Any ad inside a result grid, between a jackpot and its numbers, between tool input and output, or inside claim, correction, AI-answer or responsible-play blocks; creative styled as a result, jackpot card or community topic; unreserved space; `--color-info-surface` reuse |
| **Sticky ad** | Persistent bottom placement | **Priority 4 — below safety controls, bottom navigation and user-requested actions** *(Global Shell §6.4)* | `--color-surface`, `--color-border` top boundary, `--elevation-1`, safe-area inset | Above bottom navigation with safe spacing, **or suppressed** when they would compete; height from the reserved creative, never animated | Reserved, filled, no-fill, closed | Close control ≥44 × 44 px with accessible name "Close advertisement", keyboard reachable, **adding no height to the bar**; must never obscure numbers, inputs, focus indicators or safety guidance; page clearance **derived** from reserved height + bottom-nav height | Three competing sticky layers; deceptive close; animating height; hardcoded clearance guess; obscuring focus *(WCAG 2.4.11)* |
