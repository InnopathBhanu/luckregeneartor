# Game Page Brief Workspace

Status: working area

Use this folder for ChatGPT-created game-page implementation briefs and supporting specifications that Claude Code can execute.

Authoritative game-page implementation records remain in `03-docs/04-page-specifications/game/`. Source conflicts and founder decisions remain in `03-docs/08-decisions/`.

## Subfolders

- `briefs/` - one file per Claude Code task.
- `supporting-specifications/` - scoped source summaries, acceptance criteria, and task preparation notes.

## Brief Naming

Use stable, dated filenames:

- `YYYY-MM-DD-game-page-brief-<short-topic>.md`
- `YYYY-MM-DD-game-page-spec-<short-topic>.md`

Example:

- `2026-08-03-game-page-brief-florida-powerball-preview-route.md`

Each brief should state whether it is ready for execution or still draft.
